# Visual Guide

This page hosts the readable, page-by-page version of the project brief used in the README.

GitHub does not reliably render embedded PDFs inline in README pages, and the original stitched overview PNG became illegible when scaled down. The best compromise is:

- keep the original PDF in-repo for download and full-resolution viewing,
- render each page as its own PNG for browser-friendly preview.
